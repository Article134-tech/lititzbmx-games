# Deployment Instructions — Lititz BMX Games v1.0.0

## Repository

Create one new **public** repository:

`Article134-tech/lititzbmx-games`

Do not initialize it with a README, `.gitignore`, or license.

## Copy scope

Copy the **contents** of the folder `Lititz-BMX-Games-v1.0.0` into the cloned
repository root.

Correct:

```text
lititzbmx-games/index.html
lititzbmx-games/assets/
lititzbmx-games/brandon/index.html
```

Incorrect:

```text
lititzbmx-games/Lititz-BMX-Games-v1.0.0/index.html
```

## GitHub Pages

Publish from:

- Branch: `main`
- Folder: `/(root)`

Validate the default GitHub Pages address before configuring a custom domain.

## Expected public paths

- Hub: `https://article134-tech.github.io/lititzbmx-games/`
- Brandon: `https://article134-tech.github.io/lititzbmx-games/brandon/`

## First-release restriction

Do not add `CNAME`, change DNS, or configure `games.lititzbmx.com` during the
first deployment. Confirm the default GitHub Pages site first.
