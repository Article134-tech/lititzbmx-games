# Release Notes — v1.1.1

This usability patch adds mid-game controls so a player no longer has to finish the full experience before starting over.

- **Restart this plan** clears the current choices and scores and returns to Stage 1.
- **Return to introduction** clears the current plan and returns to the opening screen.
- Both actions require confirmation to prevent accidental data loss.
- Normal progress saving, refresh recovery, all nine stages, source links, outcomes, final proposal, branding, and print support remain unchanged.
- The public URL remains unchanged.
