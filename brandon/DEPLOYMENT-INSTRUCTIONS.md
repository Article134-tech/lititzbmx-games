# Deployment Instructions

Recommended deployment: a separate GitHub repository and GitHub Pages site.

1. Create or open the intended repository.
2. Confirm the repository and branch before copying files.
3. Copy the **contents** of this folder so `index.html` sits at repository root.
4. Confirm no unrelated repository or root files changed.
5. Commit: `Publish Help Brandon Hetrick Build a Pump Track in Warwick Township v1.1.0`
6. Push and enable GitHub Pages.
7. Verify all nine stages, the campaign logo, illustrated Brandon guide, source links, outcomes, replay, mobile layout, and print/save-as-PDF output.

Do not present the hosted game as an official township tool or approval process.
